# Roulette Giveaway для Twitch

Пульт для розыгрышей на стриме: зрители пишут кодовое слово в чат, пульт проверяет фоллоу или саб, колесо выбирает победителей, оверлей показывает всё в OBS. Сервер не нужен: это статичные страницы, их можно выложить на GitHub Pages.

## Возможности

- **Регистрация по кодовому слову.** Пульт читает чат канала и записывает тех, кто написал слово. Можно требовать точное совпадение сообщения или просто наличие слова в нём.
- **Проверка участника:** все / только фолловеры (с минимальным стажем фоллоу) / только сабы. Ботов и самого стримера можно исключить.
- **Призы — это просто места.** В настройках задаётся только их количество; победители получают «1 место», «2 место» и т.д.
- **Два режима:**
  - **На выбывание.** Колесо выбивает участников по одному, пока их не останется столько же, сколько призов. Потом между финалистами разыгрываются места. Можно выбрать, с какого приза начинается финал: с первого или с последнего (тогда главный приз достаётся последнему оставшемуся).
  - **Простой.** Один прокрут — один приз. Можно разрешить одному человеку выиграть несколько раз.
- **3D казино-рулетка** (Three.js, WebGL): деревянный обод, лакированная чаша, объёмные золотые перегородки, свет, тени и отражения, камера под наклоном. Каждый участник получает свой материал (золото, серебро, сапфир, оникс и т.д., список в `js/materials.js`). Шарик бежит навстречу колесу, отскакивает и падает в ячейку участника, а колесо останавливается так, что эта ячейка оказывается внизу, ближе к зрителю. Длинные ники уменьшаются, чтобы поместиться. При очень большом числе участников имена на колесе скрываются, а победитель виден в плашке под колесом. Three.js грузится с CDN jsDelivr, поэтому пульту и оверлею нужен интернет.
- **Оверлей-стол:** зелёное сукно с бортом; слева толпа чиби-участников (каждый окрашен материалом своего сектора, машет рукой, выбывший исчезает, победитель прыгает), по центру рулетка, справа список участников с выбыванием и местами.
- **Настройки в отдельном окне** (⚙ в шапке). При первом запуске оно открывается само, дальше на экране только рулетка и участники. Пока розыгрыш идёт, условия заблокированы.
- **Автопрокрут** до конца розыгрыша с паузой между прокрутами.
- **Сообщения в чат** от имени канала: старт, закрытие регистрации, победители. Можно отключить, тексты редактируются.
- Победитель выбирается через `crypto.getRandomValues`, без перекоса по модулю.
- Состояние сохраняется в браузере, перезагрузка страницы розыгрыш не сбрасывает.
- Тестовые участники, чтобы потренироваться без стрима.

## Настройка

### 1. Приложение в Twitch

1. Откройте [dev.twitch.tv/console/apps](https://dev.twitch.tv/console/apps) → **Register Your Application**. Нужно именно **Application**, а не Extension.
2. **OAuth Redirect URLs** — добавьте оба адреса:
   - `http://localhost:5500/` для локального запуска;
   - `https://lapizwcg.github.io/TWITCH_RouletteGiveaway/`, если будете выкладывать на GitHub Pages.
3. **Category:** Broadcaster Suite. **Client Type:** Public.
4. Скопируйте **Client ID** в `js/config.js`. Client Secret не нужен, его никуда не вставляйте.

### 2. Адреса

Рулетка опубликована на GitHub Pages, запускать ничего не нужно:

- пульт: https://lapizwcg.github.io/TWITCH_RouletteGiveaway/
- оверлей: https://lapizwcg.github.io/TWITCH_RouletteGiveaway/overlay.html

Каждый `git push` в `main` обновляет сайт примерно за минуту.

Для разработки можно запустить локальный сервер (нужен Node.js) — тогда пульт на http://localhost:5500/:

```bash
node server.mjs
```

### 3. OBS

Пульт и оверлей обмениваются данными внутри одного браузера, поэтому **оба должны быть открыты в OBS** и с одного адреса (оба с GitHub Pages или оба с localhost):

1. **Пульт:** Док-панели → Пользовательские док-панели браузера (Docks → Custom Browser Docks) → адрес пульта. Войдите через Twitch прямо в доке.
2. **Оверлей:** Источник → Браузер (Browser Source) → адрес оверлея, размер 1920×1080, галочку «Отключать источник, когда он не виден» снять. Список победителей в углу по умолчанию скрыт; чтобы показать, добавьте к адресу `?winners=1`.

Если пульт открыт в Chrome, а оверлей в OBS, оверлей ничего не получит: это два разных браузера.

## Права, которые запрашивает вход

| Право | Зачем |
| --- | --- |
| `moderator:read:followers` | проверить фоллоу и его стаж |
| `channel:read:subscriptions` | проверить саб |
| `user:write:chat` | писать объявления в чат |

Входить нужно аккаунтом самого стримера: список сабов Twitch отдаёт только владельцу канала.

## Структура

```
index.html, css/panel.css, js/panel.js   пульт
overlay.html, css/overlay.css, js/overlay.js   оверлей для OBS
js/giveaway.js   правила розыгрыша (без интерфейса)
js/wheel.js      колесо на canvas
js/twitch.js     вход, Helix API, чтение чата
js/bus.js        связь пульта и оверлея
js/config.js     Client ID
server.mjs       локальный сервер
```
